# SimpleUI

**A lightweight, easy-to-use UI library for C++ games built with [raylib](https://www.raylib.com/).**

> **Status:** Early development. The public API, installation steps, and supported widgets are still being defined.

SimpleUI aims to make adding interfaces to raylib games straightforward, with a focus on readable C++ code, minimal boilerplate, and reusable UI components.

## Goals

- **Simple integration:** Add UI to an existing raylib project without unnecessary setup.
- **Lightweight design:** Keep dependencies and overhead to a minimum.
- **Reusable components:** Build interfaces from composable elements.
- **Developer-friendly API:** Make common UI tasks easy to express and maintain.

## Getting started

Installation instructions and a working example will be added once the initial public API is ready.

**Requirements (planned):**
- C++17 or newer
- raylib 5.x
- CMake (for the provided build integration)
